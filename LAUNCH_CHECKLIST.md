## 📋 Checklist de Início (Do Zero)

### Dia 1: Setup (2 horas)
- [ ] Instalar JDK 21
  ```bash
  # Windows
  choco install openjdk21
  
  # macOS
  brew install openjdk@21
  
  # Linux
  sudo apt-get install openjdk-21-jdk
  ```

- [ ] Instalar IDE
  ```
  Recomendado: IntelliJ IDEA Community
  Alternativa: VS Code + Java Extensions
  ```

- [ ] Clonar repositório
  ```bash
  git clone <repo-url>
  cd java-career-roadmap
  ```

- [ ] Configurar Git
  ```bash
  git config --global user.name "Seu Nome"
  git config --global user.email "seu.email@domain.com"
  ```

- [ ] Ler [QUICK_START.md](QUICK_START.md)

### Dia 2: Primeiro Commit (1 hora)

  ```bash
  git checkout -b feat/module-1-study
  ```

- [ ] Executar 02-exemplos/HelloWorld.java

- [ ] Fazer exercício 01 em 03-exercicios/

- [ ] Fazer primeiro commit
