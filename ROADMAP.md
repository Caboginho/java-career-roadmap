# Roadmap Detalhado - Java Career 2026

## FASE 1: Fundamentos Absurdamente Fortes

### Duração: 2–3 meses

#### Módulo 1 — Lógica e Java Básico (4 semanas)
**Objetivo**: Dominar completamente programação procedural.

**Estudar**:
- [ ] Variáveis e tipos primitivos
- [ ] Operadores (aritméticos, lógicos, bitwise)
- [ ] Condições (if, switch)
- [ ] Loops (for, while, do-while)
- [ ] Métodos e passagem de parâmetros
- [ ] Arrays e matrizes
- [ ] Entrada e saída (Scanner, System.out)
- [ ] Debugging e tratamento de erros

**Exercícios**: 100 exercícios variados

**Mini Projetos**:
- [ ] Calculadora com operações básicas
- [ ] Conversor (temperatura, moeda, etc)
- [ ] Jogo da adivinhação
- [ ] Sistema bancário simples

---

#### Módulo 2 — OOP Profissional (3 semanas)
**Objetivo**: Dominar OOP com SOLID básico.

**Estudar**:
- [ ] Classes e Objetos
- [ ] Construtores e destrutores
- [ ] Encapsulamento (getters/setters)
- [ ] Herança
- [ ] Polimorfismo
- [ ] Abstração (abstract classes)
- [ ] Interfaces
- [ ] SOLID básico (S, O, L)

**Exercícios**: 50 exercícios OOP

**Mini Projetos**:
- [ ] Sistema escolar (alunos, professores, disciplinas)
- [ ] Biblioteca (livros, membros, empréstimos)
- [ ] RPG simples (personagens, ataques, defesa)

---

#### Módulo 3 — Estruturas de Dados (3 semanas)
**Objetivo**: Implementar estruturas do zero.

**Estudar**:
- [ ] Pilhas (Stack)
- [ ] Filas (Queue)
- [ ] Listas (ArrayList, LinkedList)
- [ ] Árvores (Binary Tree, BST)
- [ ] HashMap e HashSet
- [ ] Algoritmos de busca (Linear, Binary)
- [ ] Algoritmos de ordenação (Bubble, Quick, Merge)
- [ ] Análise Big O

**Exercícios**: 50 exercícios DS

**Projetos**:
- [ ] Agenda inteligente com busca
- [ ] Simulador de fila de atendimento
- [ ] Árvores binárias de busca

---

#### Módulo 4 — Java Moderno (3 semanas)
**Objetivo**: Programação funcional e concorrência.

**Estudar**:
- [ ] Streams API
- [ ] Lambdas
- [ ] Optional<T>
- [ ] Functional Interfaces
- [ ] Records (Java 16+)
- [ ] Sealed classes (Java 17+)
- [ ] Generics avançados
- [ ] Threads e concorrência
- [ ] Synchronized, volatile, atomic

**Exercícios**: 50 exercícios

**Projetos**:
- [ ] Processador de arquivos com Streams
- [ ] Paralelismo com ExecutorService
- [ ] Chat TCP com Threads

---

## FASE 2: Backend Java Profissional

### Duração: 3–4 meses

#### Módulo 5 — Banco de Dados (3 semanas)
**Objetivo**: SQL e modelagem profissional.

**Estudar**:
- [ ] SQL fundamentals (SELECT, INSERT, UPDATE, DELETE)
- [ ] Joins (INNER, LEFT, RIGHT, FULL)
- [ ] Agregações (GROUP BY, HAVING)
- [ ] Subqueries
- [ ] Índices e otimização
- [ ] Procedures e functions
- [ ] Transactions (ACID)
- [ ] PostgreSQL específico
- [ ] Modelagem ER

**Exercícios**: 50 exercícios SQL

**Projeto**:
- [ ] Sistema financeiro SQL-first (contas, transações, relatórios)

---

#### Módulo 6 — Spring Boot (4 semanas)
**Objetivo**: Construir APIs REST profissionais.

**Estudar**:
- [ ] Injeção de Dependência
- [ ] Controllers REST
- [ ] Services e business logic
- [ ] Repositories (Spring Data JPA)
- [ ] DTOs e ModelMapper
- [ ] Validação (Jakarta Validation)
- [ ] Exception handling global
- [ ] Logging (SLF4J, Logback)
- [ ] Swagger/OpenAPI

**Exercícios**: 50 exercícios

**Projeto**:
- [ ] API profissional completa (CRUD, validações, erro handling)

---

#### Módulo 7 — Spring Security (2 semanas)
**Objetivo**: Autenticação e autorização.

**Estudar**:
- [ ] JWT (JSON Web Tokens)
- [ ] OAuth2
- [ ] Roles e Permissions
- [ ] Refresh Tokens
- [ ] CORS e CSRF
- [ ] Password encoding (BCrypt)
- [ ] Stateless authentication

**Exercícios**: 30 exercícios

**Projeto**:
- [ ] Sistema autenticado completo com JWT

---

#### Módulo 8 — JPA/Hibernate (3 semanas)
**Objetivo**: ORM avançado.

**Estudar**:
- [ ] Mapeamento objeto-relacional
- [ ] Relacionamentos (1:1, 1:N, N:N)
- [ ] Lazy vs Eager loading
- [ ] Query optimization
- [ ] JPQL e Criteria API
- [ ] Paginação
- [ ] Caching (L1, L2)
- [ ] Migrations (Flyway, Liquibase)

**Exercícios**: 50 exercícios

**Projeto**:
- [ ] ERP backend com relacionamentos complexos

---

#### Módulo 9 — Testes (2 semanas)
**Objetivo**: Cobertura profissional e TDD.

**Estudar**:
- [ ] JUnit 5
- [ ] Mockito
- [ ] Testes unitários
- [ ] Testes de integração
- [ ] Test Containers
- [ ] TDD (Test-Driven Development)
- [ ] Coverage analysis
- [ ] Testes em REST APIs

**Exercícios**: 40 exercícios

**Projeto**:
- [ ] Cobertura profissional (80%+ de coverage)
