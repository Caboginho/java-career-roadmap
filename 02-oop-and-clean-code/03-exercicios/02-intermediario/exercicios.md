# Exercícios Intermediários

1. Crie uma classe `Disciplina` que armazena várias notas.
2. Crie uma classe `Boletim` que contém aluno e disciplinas.
3. Implemente média por disciplina e média geral.
4. Crie um serviço `ClassificadorDeAprovacao`.
5. Evite código duplicado entre classes.
6. Use `List` para armazenar coleções de objetos.
7. Retorne listas imutáveis quando expor dados internos.
8. Crie testes com `assert` para os métodos de domínio.
9. Refatore nomes genéricos como `x`, `n1`, `obj` e `calc`.
10. Separe impressão no console da regra de cálculo.
