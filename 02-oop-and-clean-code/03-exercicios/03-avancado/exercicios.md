# Exercícios Avançados

1. Crie um mini sistema de biblioteca com livros, usuários e empréstimos.
2. Modele um carrinho de compras com itens, subtotal e total.
3. Implemente uma regra de desconto sem misturar com impressão de relatório.
4. Crie uma classe de relatório que recebe objetos prontos e apenas apresenta dados.
5. Adicione tratamento para boletim sem disciplinas.
6. Crie uma classe `HistoricoEscolar` com vários boletins.
7. Refatore um método grande em três métodos menores.
8. Identifique uma responsabilidade mal posicionada e mova para a classe correta.
9. Escreva testes para cenários de erro.
10. Documente uma decisão de design em `05-diagramas/` ou `docs/`.
