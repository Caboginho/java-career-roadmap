# ADR-001: Estrutura Profissional do Repositorio

## Status

Aceito

## Contexto

O repositorio precisa funcionar como material de estudo, portfolio tecnico e base de projetos reais.

## Decisao

Organizar o projeto com modulos numerados, projetos flagship, documentacao centralizada, templates GitHub, workflows de validacao e convencoes explicitas.

## Consequencias

- A navegacao fica previsivel.
- O repositorio comunica maturidade para recrutadores e colaboradores.
- Fica mais simples expandir conteudo sem quebrar o padrao.
- Ha mais arquivos de governanca para manter atualizados.
