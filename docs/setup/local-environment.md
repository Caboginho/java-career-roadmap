# Ambiente Local

## Requisitos

- JDK 21+
- Git
- Docker 24+
- Docker Compose 2+
- Node.js LTS para projetos React
- IDE Java, como IntelliJ IDEA ou VS Code

## Primeiro Fluxo

```bash
git clone <repo-url>
cd java-career-roadmap
```

Depois leia `QUICK_START.md` e inicie pelo modulo mais adequado ao seu nivel.
