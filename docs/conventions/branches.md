# Convencao de Branches

## Branches Principais

- `main`: versao estavel e apresentavel do repositorio.
- `develop`: integracao de conteudos em andamento.

## Branches de Trabalho

```text
feature/module-01
feature/project-erp
fix/sql-queries
docs/readme-update
```

## Regras Praticas

- Uma branch deve representar uma mudanca coesa.
- Prefira nomes curtos e objetivos.
- Abra pull request para revisar conteudo, exercicios e projetos.
- Mantenha `main` sempre funcional.
