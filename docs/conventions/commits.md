# Convencao de Commits

Use Conventional Commits para manter historico claro e automatizavel.

## Formato

```text
tipo: descricao
```

## Tipos

- `feat`: nova funcionalidade, modulo, exercicio ou projeto.
- `fix`: correcao de bug, erro de conteudo ou exemplo quebrado.
- `docs`: alteracoes em documentacao.
- `refactor`: melhoria interna sem mudar comportamento.
- `test`: adicao ou ajuste de testes.
- `chore`: manutencao, configuracao ou automacao.

## Exemplos

```text
feat: add module 01 exercises
fix: correct binary search implementation
docs: update roadmap
refactor: improve oop examples
test: add junit tests for services
chore: configure project health workflow
```
