# Visao de Arquitetura

Este repositorio usa uma organizacao em tres camadas:

- Modulos educacionais para evolucao guiada.
- Projetos flagship para portfolio profissional.
- Documentacao e automacao para padronizar qualidade.

## Principios

- Clareza antes de complexidade.
- Projetos documentados como produtos reais.
- Testes e CI/CD desde o inicio.
- Decisoes arquiteturais registradas em ADRs.
- Separacao entre estudo, pratica, portfolio e operacao.
