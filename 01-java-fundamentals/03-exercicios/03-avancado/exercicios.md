# Exercícios Avançados

1. Implemente um jogo de adivinhação com limite de tentativas.
2. Crie um simulador simples de conta bancária com depósito e saque.
3. Ordene um array manualmente usando bubble sort.
4. Crie uma matriz 3x3 e some sua diagonal principal.
5. Monte um processador de texto que conta palavras, letras e espaços.
6. Implemente uma calculadora com menu e repetição até o usuário sair.
7. Crie um relatório de notas com maior nota, menor nota, média e status final.
8. Simule login com três tentativas.
9. Crie um conversor de unidades com métodos separados.
10. Refaça um exercício anterior melhorando nomes, métodos e validações.
