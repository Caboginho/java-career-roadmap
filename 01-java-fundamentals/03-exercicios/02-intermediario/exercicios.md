# Exercícios Intermediários

1. Crie um método que recebe um array de notas e retorna a média.
2. Conte quantos números pares existem em um array.
3. Inverta os valores de um array sem usar bibliotecas.
4. Gere os primeiros 20 números da sequência de Fibonacci.
5. Verifique se um número é primo.
6. Simule um menu com `switch`.
7. Crie um método para calcular IMC e classificar o resultado.
8. Leia uma frase fixa e conte quantas vogais ela possui.
9. Encontre o menor e o maior valor de um array.
10. Crie validações para impedir divisão por zero.
