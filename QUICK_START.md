## 🚨 Se Ficar Preso

### Problema: "Não sei instalar JDK"
→ Siga: https://www.oracle.com/java/technologies/downloads/

### Problema: "Meu código não compila"
→ Leia a mensagem de erro com atenção
→ Procure a linha mencionada
→ Verifique sintaxe

### Problema: "Exercício muito difícil"
→ Vá para 02-exemplos/ e procure padrão similar
→ Entenda o exemplo
→ Adapte para seu exercício

### Problema: "Não consigo pensar no código"
→ Escreva em português o que quer fazer
→ Depois traduza para Java
→ Revise lógica antes de codificar
